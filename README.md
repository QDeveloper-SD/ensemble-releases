# Ensemble desktop releases

Installers for Windows, macOS and Linux are published here as releases, and
installed copies of Ensemble check this page for updates when they start.

- **Download:** the [latest release](https://github.com/QDeveloper-SD/ensemble-releases/releases/latest)
- **Create your account and read how it works:** [ensemble.investments](https://ensemble.investments)

Install notes per OS appear on each release. Ensemble is software; it is not
a broker-dealer or an investment adviser and does not give investment advice.
Trading involves risk, including loss of principal.

The source is private. This repository holds only releases.
